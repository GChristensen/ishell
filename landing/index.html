iShell is a natural-language command line for Firefox and Chrome. Press Ctrl+Space, type what you want, and the result appears in the same window before you even press Enter.

01what-it-is

Commands are shortcuts for things you do on the Web every day. They cut out repetitive clicking and let you get more done, faster, with interactive results shown right where you typed.

Dozens of commands ship with the add-on, and you can write your own in JavaScript. This is the main power of this add-on. See the full list of built-in commands.

02syntax

Commands read like sentences.

A verb, an object and a few prepositions. The parser works out which word fills which role, suggests the likeliest reading as you type, and learns the ones you pick most.

04authoring

Write your own commands.

Declare the arguments once and the parser does the rest. For show-text hey! in popup, iShell hands hey! and popup strings straight to the command handler methods (execute in the example).

Commands have full access to the browser WebExtension APIs and jQuery, and previews are plain HTML and CSS, so they can be as rich as you like.

tutorial → class-based syntax →
command editor · show-text.js 
/**
    Displays the given message as a notification
    or prints it to the browser console.

    @command
    @uuid 5BDEFC27-CA9F-4F41-85E4-8B358154E2FC
    @description An object-oriented command with arguments.
 */
class ShowText {
    constructor(args) {
        args[OBJECT] = {nountype: noun_arb_text, label: "message"};
        args[IN] = {nountype: ["popup", "log"], label: "destination"};
    }

    execute(args) {
        const destination = args[IN]?.text;
        const message = args[OBJECT]?.text;

        if (destination === "log")
            console.log(message);
        else
            cmdAPI.notify(message);
    }
}

Eleven prepositions, plus the nameless object that follows the verb. The highlighted three are new in iShell and were not part of the original Ubiquity.

05lineage

Ubiquity, brought back.

iShell is a WebExtensions revival of Mozilla Ubiquity, an ingenious experiment in linguistic user interfaces. It brings back its full functionality with a clean, modern, object-oriented authoring API.

What changed

Ubiquity let you subscribe to third-party commands that updated themselves. For security reasons iShell has no such model: you keep third-party code in the command editor yourself, using the install command.

If you can write a little JavaScript, that is all it takes to automate the Web APIs you use or to extend the browser without much effort.
