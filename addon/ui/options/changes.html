v1.3 September 19, 2026

  • Added new command: duck. It searches DuckDuckGo and requires no API keys, unlike the google command.
  • The images command now browses Bing Images and does not require API keys anymore. The google command does not show search results in its preview since Google closed its search API.
  • The shorten-url command now uses TinyURL because the bit.ly endpoint it relied on was shut down. The bitly alias was renamed to tinyurl.
  • The current-ip command now uses the ipwho.is service (with seeip.org as a fallback) instead of ipapi.co, which requires solving a Cloudflare challenge.
  • The libgen command was updated to the current markup and query format of libgen.li.
  • The imdb command was repaired: it lists movie and TV titles with posters, years and cast using the IMDB suggestion service.

v1.2 August 17, 2026

  • Wrapping a preposition's argument in double quotes - for example, for "further review" - makes the spaces within it available to autocompletion. Quoting a multi-word argument like this lets autocompletion treat the entire phrase as a single unit, including the spaces. Previously, without quotes, autocompletion only recognized the first word of the argument.
